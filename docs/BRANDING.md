# LidSwitch branding

The LidSwitch icon combines a laptop, an external monitor, and a single motion
arrow. The laptop hinge is the origin of the arrow, tying the visual directly
to the lid-triggered display handoff.

Palette:

- Deep navy: application tile and macOS utility character.
- Warm off-white: the two display frames.
- Mint teal: the automatic handoff action.

The final raster master is `Assets/AppIcon.png`; the packaged macOS resource is
`Resources/AppIcon.icns`.

The icon was produced with OpenAI's built-in image generation tool using this
final edit prompt:

> Simplify the provided LidSwitch icon while preserving its exact core concept
> and centered composition: laptop in front, external monitor behind, mint
> switch arrow from the laptop hinge toward the monitor. Use a clean flat
> vector-like style, crisp geometric shapes, uniform line weights, at most
> three main colors, no text, no Apple logo, no trademarks, and no watermark.
